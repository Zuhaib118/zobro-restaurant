# Restaurant Website

A modern and responsive restaurant website featuring a variety of delicious Pakistani and fast-food items.

## Features
- Pakistani traditional dishes
- Pizza, burgers, sandwiches, and rolls
- Momos, gol gappay, samosay, and roghni naan
- Attractive and user-friendly design
- Contact and WhatsApp ordering information

## Technologies Used
- HTML
- CSS
- JavaScript

## About
This project is designed to provide customers with an easy and convenient way to explore the restaurant menu and contact us for orders.
